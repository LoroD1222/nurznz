# NUR Zanzibar

Next.js 15 App Router implementation of the NUR Zanzibar Figma home page.

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS v4
- Radix Slot and shadcn-style UI primitives

## Commands

```bash
npm run dev
npm run lint
npx tsc --noEmit
npm run build
```

The site is configured with App Router metadata, `robots.txt`, `sitemap.xml`,
local Figma assets, and JSON-LD structured data.
